Passkeys

Each operation asks for approval in the toolbar popup. Private keys remain in rbw. Select “Use another authenticator” to use a security key or the browser’s built-in provider. Refresh existing site tabs after changing this setting.

Autofill

Managed by your browser configuration.

HTTP sends passwords without encryption. Enable this only for trusted local or private network sites.

Fills a matching login as soon as a page loads, without any interaction. Off by default for safety.

How login URIs without their own match setting are compared with the current page. rbw’s default comes from rbw config set defaultUriMatch; choose another value to override it in this browser only. Domain and subdomains (rbw’s default) matches the saved host and hosts below it: a login for example.com also fills login.example.com. Base domain matches every host of the same registered domain, as Bitwarden does: login.example.com also fills www.example.com. Starts with and Regular expression are advanced options that can expose logins to unintended pages.

On types values quickly and animates the filled fields. Plaid adds the crab typing effect. Off fills immediately without animation.

The security code is left untouched by default. Choose whether to fill it or copy it to the clipboard; clipboard copies follow rbw’s configured timeout. Card type is filled when the page exposes a recognized card-type field. Forms are never submitted automatically.

Autofill blocklist

One entry per line. A domain blocks that domain and its subdomains. Use a full URL to block only that path and its subpaths. Lines starting with # are ignored.

Login capture

After a form is submitted, an rbw overlay on the page lets you save a new login, update an existing one, or dismiss the suggestion. Captured credentials expire after two minutes and are never saved to browser storage.

Appearance

Off by default: fetching icons reveals which sites are in your vault to those sites.

Icons are fetched directly from sites without cookies or a referrer. No third-party icon service is used.

Permissions and privacy

Website access enables passkeys, login capture, and autofill. Vault keys stay with rbw-agent. This extension has no telemetry and does not cache your vault in browser storage.

Attachments are saved by the native host into your configured Downloads directory. The agent controls copied-value clearing.
